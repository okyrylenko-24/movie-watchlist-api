Movie Watchlist API

Це невеликий REST API для ведення списку фільмів. У ньому можна додавати фільми, переглядати список, змінювати статус перегляду та видаляти записи.

Проєкт створений для практичної роботи №1 «Контейнеризація додатку» з дисципліни «Адміністрування Unix-подібних ОС».

Для розробки використано Java 25, Spring Boot, Maven, PostgreSQL 17, Docker, Docker Compose, Bash та pgAdmin.

Для запуску потрібно встановити й запустити Docker Desktop, створити файл .env за зразком .env.example і вказати свої паролі. Потім у папці проєкту відкрити Git Bash та виконати команду:

bash ./deploy.sh

Скрипт автоматично збирає застосунок і запускає три контейнери: Java API, PostgreSQL та pgAdmin.

Після запуску API доступний за адресою http://localhost:8080/api/movies, а pgAdmin - http://localhost:5050.

API підтримує запити GET, POST, PATCH та DELETE для роботи зі списком фільмів.

Контейнери взаємодіють через Docker-мережу. Дані PostgreSQL зберігаються в Docker Volume, тому не зникають після пересоздання контейнера з тим самим сховищем.

Щоб зупинити контейнери, потрібно виконати:

docker compose down
